Questions fréquentes

Où est enregistrée ma progression ?

Uniquement sur votre appareil. Elle peut être perdue si vous supprimez l'Application ou changez d'appareil.

Existe-t-il une version Android ?

Nous sortons d'abord sur iPhone. Nous communiquerons plus tard sur les autres plateformes.

Collectez-vous des données personnelles ?

L'application, non. Le site web collecte des statistiques de visite de base via Google Analytics. Pour plus de détails, consultez la Politique de confidentialité.

Iltonggi · Politique de confidentialité

1. Informations collectées — aucune

Iltonggi (« l'Application ») est un jeu mobile exploité par un développeur indépendant, Davy Kim (ipe Studio). L'Application n'a ni compte ni connexion, et ne collecte ni n'envoie à aucun serveur de données personnelles telles que votre nom, e-mail, coordonnées, localisation ou identifiants d'appareil. Votre progression et vos réglages sont stockés uniquement sur votre appareil et sont supprimés lorsque vous supprimez l'Application. Le pseudo que vous choisissez dans le jeu et vos données de partie sont stockés uniquement sur votre appareil ; nous ne les recevons ni ne les collectons.

L'Application ne contient aucune publicité, aucun outil d'analyse ni aucun SDK de suivi.

2. Informations météo

Pour afficher la météo régionale, l'Application télécharge un fichier public (weather.json) depuis iltonggi.ipe.rest dès qu'elle est connectée à Internet. Ce fichier rassemble une fois par heure la météo des 24 villes du jeu et est identique pour tous les utilisateurs. L'Application n'envoie alors aucune donnée personnelle — ni localisation, ni identifiant d'appareil, ni données de jeu — et ne contacte directement aucun fournisseur de données météo.

Comme pour toute requête web ordinaire, le journal du serveur de notre hébergeur (GitHub Pages) peut enregistrer l'adresse IP de votre appareil ; nous ne collectons ni n'utilisons ce journal. Si la météo ne peut pas être téléchargée (par exemple hors ligne), l'Application affiche un temps dégagé et le jeu fonctionne normalement. La dernière météo reçue est stockée temporairement sur votre appareil et supprimée lorsque vous supprimez l'Application.

Source des données météo : MET Norway (CC BY 4.0).

Les données météo sont fournies par MET Norway. Nous les récupérons nous-mêmes et les publions sous forme de fichier public ; aucune information sur les utilisateurs de l'Application n'est donc transmise à MET Norway.

Iltonggi · Conditions d'utilisation

3. Nature du service

Les fonctions essentielles de l'Application fonctionnent hors ligne ; elle n'utilise Internet que de façon facultative, pour afficher la météo (si elle ne peut pas être téléchargée, un temps dégagé est affiché). Les données de jeu sont stockées sur votre appareil. Des données peuvent être perdues si vous changez d'appareil, supprimez l'Application ou réinitialisez votre appareil, et nous ne pourrons peut-être pas les restaurer.

4. Informations météo

La météo affichée dans l'Application est une information indicative utilisée pour la mise en scène et les règles du jeu (modificateurs de combat). Nous ne garantissons ni qu'elle correspond aux conditions météorologiques réelles ni qu'elle sera toujours disponible. Si les informations météo sont absentes ou obsolètes, un temps dégagé peut être utilisé.

Source des données météo : MET Norway (CC BY 4.0).

L'Application est fournie en l'état. Dans la mesure permise par la loi, nous ne sommes pas responsables des dommages indirects ou accessoires résultant de votre utilisation de l'Application. L'Application est une œuvre de création inspirée de l'époque des Trois Royaumes de Corée et peut différer des faits historiques.
