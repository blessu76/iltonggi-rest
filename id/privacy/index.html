Kebijakan Privasi

Berlaku sejak: 28 Oktober 2026 · Dioperasikan oleh Davy Kim (ipe Studio)

Singkatnya: Aplikasi Iltonggi dan situs web ini tidak mengumpulkan informasi pribadi Anda.

1. Informasi yang kami kumpulkan — tidak ada

Iltonggi (“Aplikasi”) adalah game mobile yang dioperasikan oleh pengembang perorangan, Davy Kim (ipe Studio). Aplikasi tidak memiliki akun atau proses masuk, dan tidak mengumpulkan maupun mengirim ke server mana pun informasi pribadi seperti nama, email, kontak, lokasi, atau pengenal perangkat. Progres game dan pengaturan Anda hanya disimpan di perangkat Anda dan akan terhapus saat Anda menghapus Aplikasi.

Aplikasi tidak berisi iklan, analitik, maupun SDK pelacakan.

2. Informasi cuaca

Untuk menampilkan cuaca daerah, Aplikasi mengunduh file publik (weather.json) dari iltonggi.ipe.rest setiap kali terhubung ke internet. File ini mengumpulkan cuaca 24 kota di dalam game sekali setiap jam dan sama untuk semua pengguna. Dalam proses ini, Aplikasi tidak mengirimkan informasi pribadi apa pun (tidak ada lokasi, pengenal perangkat, atau data game) dan juga tidak terhubung langsung ke penyedia cuaca mana pun.

Seperti pada permintaan web biasa, log server hosting kami (GitHub Pages) dapat mencatat alamat IP perangkat Anda; kami tidak mengumpulkan atau menggunakan log tersebut. Jika cuaca tidak dapat diunduh (misalnya saat offline), Aplikasi menampilkan cuaca cerah dan game tetap berjalan normal. Cuaca terakhir yang diterima disimpan sementara di perangkat Anda dan dihapus saat Anda menghapus Aplikasi.

Data cuaca: MET Norway (CC BY 4.0).

3. Situs web

Situs web iltonggi.ipe.rest tidak menggunakan cookie dan tidak menyertakan alat analitik maupun tag iklan. Font dimuat dari Google Fonts, sehingga informasi permintaan web biasa (seperti alamat IP Anda) dapat dikirim ke Google. Situs ini di-host di GitHub Pages, dan kebijakan log server GitHub berlaku.

4. Pihak ketiga

Karena kami tidak mengumpulkan informasi pribadi, tidak ada yang dapat kami bagikan kepada atau jual ke pihak ketiga. Aplikasi didistribusikan melalui Apple App Store; informasi terkait unduhan diproses oleh Apple sesuai kebijakan privasi Apple.

Data cuaca disediakan oleh MET Norway. Kami mengambilnya sendiri dan menerbitkannya sebagai file publik, sehingga tidak ada informasi pengguna Aplikasi yang diteruskan ke MET Norway.

5. Pertanyaan dan hak Anda

Untuk meminta akses, koreksi, penghapusan, atau penghentian pemrosesan informasi pribadi Anda, atau untuk mengajukan pertanyaan apa pun, tulislah ke ipe.haven@gmail.com. Perlu diketahui bahwa karena kami tidak menyimpan informasi pribadi, mungkin tidak ada yang dapat diproses.

6. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah usia 14 tahun (atau usia minimum di wilayah Anda), dan tidak mengumpulkan informasi pribadi dari pengguna mana pun.

9. Perubahan

Jika Aplikasi kelak menambahkan akun, pembayaran, atau fitur online yang mengubah data yang dikumpulkan, kami akan memperbarui kebijakan ini terlebih dahulu dan mengubah tanggal berlakunya.
