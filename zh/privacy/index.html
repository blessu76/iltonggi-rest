隐私政策

生效日期:2026年11月1日 · 运营者:Davy Kim (ipe Studio)

简而言之: 一统记应用不会收集您的个人信息。本网站通过 Google Analytics 收集基本的访问统计(第 3 条)。

1. 我们收集的信息 — 无

一统记(以下称“本应用”)是由个人开发者 Davy Kim (ipe Studio) 运营的手机游戏。本应用没有账号或登录功能,不会收集您的姓名、电子邮件、联系方式、位置或设备标识符等任何个人信息,也不会将其发送至任何服务器。您的游戏进度和设置仅保存在您的设备上,删除本应用时会一并删除。 您在游戏中设置的昵称和游戏记录仅保存在您的设备上,不会发送给我们,我们也不会收集。

本应用不包含任何广告、分析或跟踪类 SDK。

2. 天气信息

为了显示所在地区的天气,本应用在联网时会从 iltonggi.ipe.rest 下载一个公共文件(weather.json)。该文件每小时汇总一次游戏中 24 个城镇的天气,对所有用户都相同。在此过程中,本应用不会发送位置、设备标识符、游戏数据等任何个人信息,也不会直接连接天气数据提供方。

不过,由于下载文件这类普通网络请求的特性,托管服务(GitHub Pages)的服务器日志中可能会记录您设备的 IP 地址,我们不会收集或使用该日志。如果无法获取天气(例如离线),将显示为晴天,游戏仍可正常运行。最近一次获取的天气会临时保存在您的设备上,删除本应用时会一并删除。

天气数据来源:MET Norway (CC BY 4.0)。

3. 网站与访问统计(Google Analytics)

本条仅适用于 iltonggi.ipe.rest 网站,不适用于应用。应用不收集任何信息,也不含任何分析工具(见第 1 条);应用内显示的网站页面不会加载 Google Analytics。

在网站上,我们使用 Google Analytics 4 来了解哪些页面被阅读。它会记录页面浏览、您来自哪个页面、浏览器和设备类型、大致位置(国家或城市),以及离开本站的链接点击(仅链接地址)。它会在您的浏览器中设置 Cookie(例如 _ga,最长可保留两年)以区分不同的访问。分析中我们不会要求您提供姓名或电子邮件,也无法据此识别您本人。这些数据由 Google 代表我们处理,可能涉及韩国境外的服务器。

字体从 Google Fonts 加载,因此普通的网页请求信息(例如您的 IP 地址)可能会被发送给 Google。本网站托管于 GitHub Pages,适用 GitHub 的服务器日志政策。

如不希望被统计,您可以在浏览器设置中阻止或删除 Cookie,或使用 Google 的 Analytics 停用浏览器插件(tools.google.com/dlpage/gaoptout)。没有它们,网站的使用不受影响。

4. 第三方

应用不收集个人信息,因此没有可向第三方提供或出售的信息。在网站方面,Google(访问统计)和 GitHub(托管)按第 3 条所述处理数据;我们不会出售这些数据。应用通过 Apple App Store 分发,与下载相关的信息由 Apple 依据其隐私政策处理。

天气数据由 MET Norway 提供,由我们代为获取并以公共文件形式发布,因此本应用用户的信息不会被传送给 MET Norway。

5. 咨询与您的权利

如需查阅、更正、删除个人信息或要求停止处理,或有任何疑问,请发送邮件至 ipe.haven@gmail.com。不过,应用不持有个人信息,网站的访问统计数据也不与您的姓名或电子邮件关联,因此可能没有可查找并处理的信息。

6. 儿童

本应用不面向 14 岁以下(或您所在地区规定的最低年龄以下)的儿童,也不会向任何用户收集个人信息。
