隱私權政策

生效日期:2026年10月28日 · 營運者:Davy Kim (ipe Studio)

簡而言之: 一統記應用程式及本網站不會蒐集您的個人資料。

1. 我們蒐集的資料 — 無

一統記(以下稱「本應用」)是由個人開發者 Davy Kim (ipe Studio) 營運的手機遊戲。本應用沒有帳號或登入功能,不會蒐集您的姓名、電子郵件、聯絡方式、位置或裝置識別碼等任何個人資料,也不會將其傳送至任何伺服器。您的遊戲進度和設定僅儲存在您的裝置上,刪除本應用時會一併刪除。

本應用不包含任何廣告、分析或追蹤類 SDK。

2. 天氣資訊

為了顯示所在地區的天氣,本應用在連網時會從 iltonggi.ipe.rest 下載一個公開檔案(weather.json)。該檔案每小時彙整一次遊戲中 24 個城鎮的天氣,對所有使用者都相同。在此過程中,本應用不會傳送位置、裝置識別碼、遊戲資料等任何個人資料,也不會直接連線至天氣資料提供者。

不過,由於下載檔案這類一般網路請求的特性,代管服務(GitHub Pages)的伺服器日誌中可能會記錄您裝置的 IP 位址,我們不會蒐集或使用該日誌。如果無法取得天氣(例如離線),將顯示為晴天,遊戲仍可正常運作。最近一次取得的天氣會暫時儲存在您的裝置上,刪除本應用時會一併刪除。

天氣資料來源:MET Norway (CC BY 4.0)。

3. 網站

iltonggi.ipe.rest 網站不使用 Cookie,也不包含任何分析或廣告程式碼。字型從 Google Fonts 載入,因此一般的網頁請求資訊(例如您的 IP 位址)可能會被傳送給 Google。本網站代管於 GitHub Pages,適用 GitHub 的伺服器日誌政策。

4. 第三方

由於我們不蒐集個人資料,因此沒有可與第三方分享或出售的內容。本應用透過 Apple App Store 發行;與下載相關的資訊由 Apple 依據其隱私權政策處理。

天氣資料由 MET Norway 提供,由我們代為取得並以公開檔案形式發布,因此本應用使用者的資訊不會被傳送給 MET Norway。

5. 諮詢與您的權利

如需請求查閱、更正、刪除或停止處理您的個人資料,或有任何疑問,請寄送郵件至 ipe.haven@gmail.com。請注意,由於我們不持有任何個人資料,可能沒有可處理的內容。

6. 兒童

本應用不面向 14 歲以下(或您所在地區規定的最低年齡以下)的兒童,也不會向任何使用者蒐集個人資料。
